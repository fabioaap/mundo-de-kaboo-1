# Bem-vindo

Esta é uma área de ajuda em **linguagem simples**, pensada para **pais, responsáveis e
professores**. Aqui você entende, sem termos técnicos, o que é a plataforma e como
começar a usar.

## O que você encontra aqui

- [O que é a plataforma](./o-que-e.md) — a ideia por trás e as duas marcas.
- [Como funciona](./como-funciona.md) — do código de acesso ao conteúdo, passo a passo.
- [Perguntas frequentes](./faq.md) — dúvidas comuns respondidas de forma direta.

## Em uma frase

É uma plataforma de **livros, áudios, vídeos e formações** para crianças aprenderem
brincando — e para professores apoiarem esse aprendizado. Você entra com um **código de
acesso** (voucher) e libera o conteúdo.

Se ficou com qualquer dúvida, a página de [perguntas frequentes](./faq.md) é o melhor
lugar para começar.
