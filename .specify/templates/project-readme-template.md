## 🚀 Como Começar

### Pré-requisitos

- Node.js 18+ (ou sua runtime/linguagem)
- [Outras dependências]

### Instalação

```bash
# Clone o repositório
git clone https://github.com/usuario/projeto.git

# Entre no diretório
cd projeto

# Instale as dependências
npm install  # ou pnpm install, yarn install, pip install -r requirements.txt, etc

# Configure as variáveis de ambiente
cp .env.example .env
# Edite .env com suas configurações
```

### Executando em Desenvolvimento

```bash
npm run dev  # ou pnpm dev, yarn dev, python manage.py runserver, etc
```

O projeto estará disponível em `http://localhost:[PORTA]`
